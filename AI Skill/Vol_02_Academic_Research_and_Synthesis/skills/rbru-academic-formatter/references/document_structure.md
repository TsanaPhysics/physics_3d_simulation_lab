# โครงสร้างเอกสารวิชาการตามมาตรฐาน RBRU
> [!NOTE]
> โครงสร้างองค์ประกอบที่จำเป็นสำหรับเอกสารคำสอน เอกสารประกอบการสอน และตำราวิชาการ เพื่อใช้เสนอขอผลงานทางวิชาการ มหาวิทยาลัยราชภัฏรำไพพรรณี

---

## 1. โครงสร้างภาพรวม (Overall Document Architecture)
เอกสารทางวิชาการที่สมบูรณ์จะแบ่งออกเป็น 3 ส่วนหลัก ดังนี้:

```text
┌────────────────────────────────────────────────────────┐
│ 1. ส่วนนำ (Front Matter)                               │
│    - ปกนอก, ปกใน, คำนำ, สารบัญ                          │
│    - แผนบริหารการสอนประจำวิชา (Course Syllabus)           │
├────────────────────────────────────────────────────────┤
│ 2. ส่วนเนื้อหาหลัก (Body Matter)                        │
│    - บทที่ 1 ถึง บทสุดท้าย                              │
│    - แต่ละบทประกอบด้วยแผนการสอนประจำบท, เนื้อหา, แบบฝึกหัด  │
├────────────────────────────────────────────────────────┤
│ 3. ส่วนท้าย (Back Matter)                               │
│    - บรรณานุกรม (Bibliography)                         │
│    - ภาคผนวก (Appendices)                              │
│    - ประวัติผู้เขียน (Author Biography)                 │
└────────────────────────────────────────────────────────┘
```

---

## 2. ส่วนนำ (Front Matter)
ส่วนนี้มีความสำคัญในการปูพื้นฐานการเรียนการสอนและขอบเขตของรายวิชา ประกอบด้วย:
1.  **ปกนอกและปกใน (Outer & Inner Cover)**: ระบุชื่อเอกสาร, ชื่อวิชา, รหัสวิชา, ชื่อผู้เขียน, และสังกัดคณะ/มหาวิทยาลัย
2.  **คำนำ (Preface)**: วัตถุประสงค์ในการจัดทำเอกสาร และขอบเขตของเนื้อหา
3.  **สารบัญ (Table of Contents)**: ประกอบด้วย สารบัญเนื้อหา, สารบัญตาราง, และสารบัญภาพ
4.  **แผนบริหารการสอนประจำวิชา (Course Management Plan / Syllabus)**:
    *   รหัสวิชา ชื่อวิชา จำนวนหน่วยกิต
    *   คำอธิบายรายวิชา (Course Description)
    *   วัตถุประสงค์ทั่วไป
    *   หัวข้อเนื้อหาและชั่วโมงการสอนต่อสัปดาห์
    *   กิจกรรมการเรียนการสอนและสื่อการสอน
    *   การวัดและประเมินผลการเรียนรู้

---

## 3. ส่วนเนื้อหาหลัก (Body Matter - Chapters)
เนื้อหารายบทต้องเขียนอย่างเป็นระบบ โดยเกณฑ์ของ RBRU แนะนำให้แต่ละบทมีโครงสร้างดังนี้:
1.  **แผนบริหารการสอนประจำบท (Chapter Syllabus)**:
    *   หัวข้อเนื้อหาประจำบท
    *   วัตถุประสงค์เชิงพฤติกรรม (Behavioral Objectives / Learning Outcomes)
    *   กิจกรรมการเรียนการสอนประจำบท
    *   สื่อที่ใช้สอน
    *   การประเมินผลการเรียนรู้ประจำบท
2.  **เนื้อหาหลัก (Core Content)**: อธิบายหลักการ ทฤษฎี สูตร ตัวอย่างเชิงคำนวณ หรือขั้นตอนทดลองอย่างละเอียด (มีภาพ ตาราง หรือโค้ดประกอบตามสมควร)
3.  **บทสรุป (Summary)**: สรุปประเด็นสำคัญของบทเรียนในตอนท้าย
4.  **แบบฝึกหัดท้ายบท (Exercises)**: คำถามเพื่อทบทวนความเข้าใจของผู้เรียน (ควรมีคำถามเชิงวิเคราะห์และคำนวณ)
5.  **เอกสารอ้างอิงประจำบท (Chapter References)**: แหล่งอ้างอิงที่ใช้เฉพาะในบทนั้นๆ (ถ้ามี หรือจะรวมไว้ที่ท้ายเล่มทีเดียว)

---

## 4. ส่วนท้าย (Back Matter)
ส่วนรวบรวมหลักฐานและข้อมูลเสริมความน่าเชื่อถือ:
1.  **บรรณานุกรม / เอกสารอ้างอิง (Bibliography / References)**:
    *   รวบรวมแหล่งอ้างอิงทั้งหมดที่ใช้ในเล่ม
    *   จัดเรียงตามลำดับอักษรภาษาไทยก่อน แล้วตามด้วยภาษาอังกฤษ
    *   แนะนำให้เขียนตามมาตรฐาน **APA (American Psychological Association) 7th Edition**
2.  **ภาคผนวก (Appendices)**: ข้อมูลเพิ่มเติม เช่น ตารางมาตรฐาน, คู่มือการใช้งานเครื่องมือ, โค้ดโปรแกรมเวอร์ชันยาว หรือเฉลยคำตอบแบบฝึกหัด
3.  **ดัชนี (Index)** (ถ้ามี): รายการคำสำคัญและเลขหน้าที่อ้างอิงในเล่มเพื่อความสะดวกในการสืบค้น
4.  **ประวัติผู้เขียน (Author Biography)**: ประวัติการศึกษา, ประสบการณ์ทำงาน, รายวิชาที่สอน, และผลงานทางวิชาการอื่นๆ ที่ผ่านมา
