   - **แนวทางแก้ไขมาตรฐาน:** ต้องกำหนดคอลัมน์ด้วย `>{\raggedright\arraybackslash}p{...}` หรือ `>{\raggedright\arraybackslash}X` หรือ `>{\centering\arraybackslash}p{...}` เสมอ
   - เว้นวรรคระหว่างกลุ่มคำภาษาไทยในตารางอย่างเหมาะสม เพื่อให้ระบบตัดบรรทัดได้เรียบเนียนเป็นธรรมชาติ
2. **การป้องกันข้อผิดพลาดจากอักขระพิเศษ (Special Character Escaping):**
   - ในเนื้อหา ชื่อหัวข้อ คำอธิบาย และตาราง ห้ามใช้เครื่องหมายแอมเพอร์แซนด์ (`&`) เดี่ยวๆ เพราะจะถูกตีความเป็นคอลัมน์แยกใน LaTeX ส่งผลให้เกิดข้อผิดพลาด `! Misplaced alignment tab character &` ให้ escape เป็น `\&` เสมอ
3. **การตั้งค่าฟอนต์ระบบ Sarabun สำหรับ tcolorbox:**
   - ใช้ `\setmainfont{Sarabun}`, `\setsansfont{Sarabun}`, `\setmonofont{Sarabun}[Scale=0.9]` จากระบบโดยตรง หลีกเลี่ยง `[Path=...]` เมื่อมีการใช้ฟอนต์ขนาดย่อยในกล่อง tcolorbox เพื่อให้ระบบดึง font metrics ได้ครบถ้วน ปราศจากคำเตือน missing character
4. **มาตรฐานกล่องแก้โจทย์ปัญหาฟิสิกส์และวิศวกรรมระดับโลก:**
   - **Tipler & Mosca P-S-C-T Box (`psctexample`):** Picture and Strategy (P-S), Cover Solution (C), Takeaway/Remarks (T)
   - **Serway & Jewett C-C-A-F Box (`ccafsolution`):** Conceptualize (C), Categorize (C), Analyze (A), Finalize (F)

## Common Mistakes

1. **ลืมตรวจสีหรืออักขระพิเศษก่อน compile** — ทุกครั้งที่เพิ่ม TikZ หรือเนื้อหาใหม่ ให้ตรวจสอบชื่อสีและ escape `\&`
2. **Colon ท้ายประโยค** — ภาษาไทยวิชาการไม่ใช้ `:` ท้าย `ได้แก่` และ `ดังนี้`
3. **ใช้ tabularx โดยไม่ใส่ >{\raggedright\arraybackslash}** — ทำให้ข้อความภาษาไทยในตารางเบียดซ้อนทับกัน
4. **itemize แทน enumerate** ในแผนการบริหารการสอน — ใช้ enumerate เสมอสำหรับ 4 หัวข้อหลัก
5. **ลืม \noindent** — หัวข้อในแผนการบริหารการสอนต้องชิดซ้ายเสมอ
6. **Compile ครั้งเดียว** — ต้อง compile อย่างน้อย 2 รอบเพื่อให้ ToC, index และ references ถูกต้อง
7. **ลืมซิงค์แผนการสอนใน syllabus.tex** เมื่อมีการปรับลำดับบท — ต้องตรวจเช็กตารางสัปดาห์ใน syllabus ทุกครั้ง

### Phase 15: มาตรฐานการแปลงคำบรรยายภาพและตารางเป็นภาษาไทยบริสุทธิ์ (100% Thai Caption Localization & \mbox Binding)

1. **การบังคับใช้ภาษาไทยในระดับเอนจิน LaTeX:**
   - ใน XeLaTeX ร่วมกับคลาส `book.cls` และแพ็กเกจ `caption` ค่าปริยายอาจถูกคืนค่าเป็น "Figure" หรือ "Table" หากไม่ได้ประกาศบังคับในทั้งสองส่วน
   - ต้องประกาศทั้งใน Preamble และภายในบล็อก `\AtBeginDocument{...}`:
     ```latex
     \RequirePackage{caption}
     \DeclareCaptionLabelSeparator{thaisep}{\quad}
     \captionsetup{labelsep=thaisep}

     % ประกาศใน Preamble
     \renewcommand{\figurename}{\mbox{ภาพที่}}
     \renewcommand{\tablename}{\mbox{ตารางที่}}

     % บังคับใช้ใน AtBeginDocument เพื่อป้องกันแพ็กเกจอื่นเขียนทับ
     \AtBeginDocument{
         \gdef\figurename{\mbox{ภาพที่}}
         \gdef\tablename{\mbox{ตารางที่}}
         \captionsetup[figure]{name={\mbox{ภาพที่}}}
         \captionsetup[table]{name={\mbox{ตารางที่}}}
     }
     ```
2. **การป้องกันปัญหาตัดคำและแทรกช่องว่างวรรคตอนผิดจังหวะ (`\mbox{...}`):**
   - เมื่อใช้ `\XeTeXlinebreaklocale "th_TH"` ในพื้นที่แคบ เช่น Minipage (`0.48\textwidth`) เอนจินจะมองคำว่า "ภาพ" และ "ที่" เป็นพยางค์อิสระ และอาจแทรกช่องว่างวรรคตอนกลายเป็น `"ภาพ ที่ 1.1"`
   - การครอบด้วย `\mbox{ภาพที่}` และ `\mbox{ตารางที่}` จะการันตีว่าข้อความคำนำหน้าจะไม่ถูกตัดคำหรือแยกช่องว่างอย่างเด็ดขาด 100%
3. **การตรวจสอบผลลัพธ์ใน PDF:**
   - ใช้คำสั่งตรวจจับในไฟล์ PDF:
     ```bash
     pdftotext main.pdf - | grep "Figure"
     ```
     ต้องส่งออกผลลัพธ์เป็น 0 match เพื่อยืนยันว่าคำว่า "Figure" ถูกแทนที่ด้วย "ภาพที่" ทั่วทั้งเล่ม

### Phase 16: กฎการป้องกันแผนภาพเวกเตอร์ TikZ / SVG และรูปภาพล้นขอบกั้นซ้าย 1.5 นิ้ว (Strict 1.5" Left-Margin Compliance)

1. **เข้าใจกลไกการคำนวณระยะขอบของ TeX:**
   - หนังสือตำราวิชาการ มรภ.รำไพพรรณี กำหนดระยะขอบเข้าเล่ม **กั้นซ้าย 1.5 นิ้ว (3.81 ซม.)** และกั้นขวา 1.0 นิ้ว
   - คำสั่ง `\begin{figure}\centering \begin{tikzpicture}...` จะจัดกึ่งกลาง *Bounding Box รวม* ของ TikZ เข้ากับ `\textwidth`
   - หากแผนภาพมีความกว้างมากกว่า `\textwidth` หรือมีสาขาไม่สมมาตร (เช่น เส้นวนลูปขวามือ หรือข้อความยาวลอยบนเส้นประ) TeX จะขยายกล่องออกสองข้างอย่างสมมาตร ส่งผลให้ฝั่งซ้ายถูกผลักให้ยื่นกินพื้นที่ขอบกั้นซ้าย 1.5 นิ้ว ทันที: $\text{left\_overhang} = (W - \text{\textwidth}) / 2$
2. **กฎทอง 5 ข้อในการวาดและจัดวางแผนภาพเวกเตอร์:**
   - **กฎข้อที่ 1: มาตราส่วนปลอดภัย (Safe Scaling Buffer):** ครอบแผนภาพ TikZ ด้วย `\resizebox{0.88\textwidth}{!}{...}` หรือ `0.85\textwidth` เสมอ เพื่อให้มีพื้นที่กันชน (Safety Margin) ทั้งสองด้าน
   - **กฎข้อที่ 2: พิกัดสมดุลชดเชยลูป (Symmetric Balance Coordinates):** หากมีเส้นลูปวนกลับด้านขวา ต้องเพิ่มพิกัดสมมุติด้านซ้ายเสมอ เช่น:
     ```latex
     \path (leftmost_node.west) ++(-1.6,0) coordinate (lb);
     ```
     เพื่อดึง Bounding Box ให้สมดุล ทำให้ TeX จัดกึ่งกลางบล็อกหลักได้ตรงกับเนื้อหา
   - **กฎข้อที่ 3: ห้ามวางข้อความยาวบนเส้นลูกศรตั้งฉาก:** หลีกเลี่ยง `\draw (A) -| node[pos=0.25, below] {ข้อความยาว...} (B);` บนเวกเตอร์ที่ไม่มีระยะขจัดในแนวแกน เพราะข้อความจะยื่นออกไปทางซ้ายอย่างควบคุมไม่ได้ ให้เปลี่ยนเป็นกล่องข้อความกำกับในแนวตั้งใต้บล็อกหลักแทน
   - **กฎข้อที่ 4: การเว้นระยะเซลล์เครือข่ายวนซ้ำ (LSTM / Recurrent Cells Spacing):** ในโครงสร้าง Unrolled Network หากกล่องเซลล์กว้าง $W_{\text{box}}$ ระยะห่างระหว่างโหนด ($D_{\text{node}}$) ต้องมากกว่าความกว้างกล่องอย่างน้อย $1.2\text{--}1.5\text{ cm}$ เพื่อให้ลูกศรส่งสถานะ $c_t, h_t$ มีความยาวเพียงพอ และป้ายกำกับไม่ทับซ้อนกับขอบกล่อง
   - **กฎข้อที่ 5: การล็อกความสูงภาพถ่ายใน Minipage:** ภาพอุปกรณ์จริงใน Minipage คู่ (`0.48\textwidth`) ต้องกำหนด `\includegraphics[height=5.0cm,width=\textwidth,keepaspectratio]{...}` เสมอ เพื่อป้องกัน Float ปัดขึ้นหน้าใหม่หรือล้นขอบล่าง

## Known Pitfalls (2569)

- **\usepackage{hanging} + math prime** เกิด TeX capacity exceeded — ลบออก
- **headheight Sarabun 12pt** ต้อง set 43pt ไม่ใช่ 36pt
- **planbox ใน syllabus.tex** — ต้องแทนด้วย tcolorbox โดยตรงเมื่อ planbox environment ถูกลบออก
- **ลืมใส่ \mbox ใน \figurename** — ทำให้เกิดปัญหาคำฉีก "ภาพ ที่" ในกล่องแคบหรือ Minipage
- **TikZ ไม่ได้ใส่ resizebox** — ทำให้แผนภาพกินพื้นที่ขอบกั้นซ้าย 1.5 นิ้ว เสียรูปเล่มงานวิชาการ
- **Python regex** สำหรับ batch convert planbox→noindent textbf ดีกว่า manual edit ทีละไฟล์
