\chapter{การผสาน Multimodal AI ด้วย Firebase AI Logic}

การนำโมเดลภาษาขนาดใหญ่มาใช้งานบนเว็บแอปพลิเคชันยุคใหม่ จำเป็นต้องมีชั้นการเชื่อมต่อที่มีความปลอดภัยสูง ไม่เปิดเผย API Key ฝั่งไคลเอนต์ และรองรับการสตรีมคำตอบอย่างมีประสิทธิภาพ

\section{สถาปัตยกรรม Firebase AI Logic}

Firebase AI Logic ทำหน้าที่เป็นเกตเวย์ระหว่างเว็บไคลเอนต์และโมเดล Gemini API โดยส่งผ่านคำขอผ่านโครงสร้างพื้นฐานของ Google Cloud และตรวจสอบสิทธิ์ผ่าน Firebase Authentication โดยอัตโนมัติ

\section{การประมวลผลอินพุตแบบมัลติโมดัล}

ในแอปพลิเคชันตรวจสอบคุณภาพดิน ผู้ใช้สามารถถ่ายภาพหน้าดินพร้อมส่งข้อมูลพิกัด GPS และค่าที่วัดได้จากเซนเซอร์ โมเดล AI จะทำการวิเคราะห์ข้อมูลทั้ง 3 ส่วนพร้อมกัน:

\begin{equation}
\mathbf{\hat{y}}_{\text{health}} = \mathcal{M}_{\text{Gemini}}(\mathbf{I}_{\text{soil}}, \mathbf{x}_{\text{sensor}}, \mathbf{c}_{\text{context}})
\end{equation}

โดยที่ $\mathbf{I}_{\text{soil}}$ คือภาพถ่าย, $\mathbf{x}_{\text{sensor}}$ คือค่าที่อ่านได้จากหัววัด, และ $\mathbf{c}_{\text{context}}$ คือบริบทพืชที่ปลูก

\section{การบังคับโครงสร้างเอาต์พุตด้วย JSON Schema}

เพื่อป้องกันปัญหาภาพหลอน (Hallucinations) และทำให้ฝั่งไคลเอนต์สามารถประมวลผลต่อได้ทันที คำสั่งเรียกใช้งานจะกำหนด \texttt{responseMimeType: "application/json"} ร่วมกับ Schema ที่ชัดเจน ทำให้ผลลัพธ์ที่ได้ตรงตามฟิลด์ข้อมูลที่ต้องการเสมอ
