## 🛠️ 4. คำสั่งคอมไพล์เอกสาร XeLaTeX ของแต่ละเล่ม (Build Instructions)

แต่ละโฟลเดอร์ย่อยบรรจุไฟล์ `main.tex` ที่พร้อมสั่งคอมไพล์เป็น PDF หนังสือเล่มจริงได้ทันที:

```bash
# ตัวอย่าง: คอมไพล์เล่มที่ 1
cd "AI Skill/Vol_01_Virtual_Labs_3D_Simulations_AIoT"
/Library/TeX/texbin/xelatex -interaction=nonstopmode main.tex

# ตัวอย่าง: คอมไพล์เล่มที่ 3
cd "../Vol_03_AI_Agentic_Orchestration_Antigravity"
/Library/TeX/texbin/xelatex -interaction=nonstopmode main.tex
```
